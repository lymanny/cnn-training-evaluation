# 🧠 CNN Training and Evaluation

A beginner-friendly **PyTorch project** covering neural network training, loss functions, backpropagation, optimizers, hyperparameters, validation, evaluation metrics, and overfitting.

## 📚 Topics

### 1. 🎯 Loss Functions (Cross-Entropy / BCE)

Learn how loss functions measure prediction errors using Cross-Entropy and Binary Cross-Entropy.

### 2. 🔄 Backpropagation

Learn how gradients are calculated and used to improve neural network weights.

### 3. ⚙️ Optimizers (Adam / SGD)

Learn how SGD and Adam update model weights to minimize prediction errors.

### 4. 🎛️ Learning Rate, Batch Size, and Epochs

Learn how hyperparameters control weight updates, training batches, and training duration.

### 5. 📈 Training and Validation

Learn how to train neural networks and evaluate their performance on separate validation data.

### 6. 📊 Evaluation Metrics

Learn how to calculate Accuracy, Precision, Recall, and F1-score to measure classification performance.

### 7. 🔢 Confusion Matrix

Learn how to visualize correct and incorrect predictions using a confusion matrix.

### 8. 🧩 Overfitting and Underfitting

Learn how to identify underfitting and overfitting by comparing training and validation loss.

## 🔄 Training and Evaluation Workflow

```text
Training Dataset
       ↓
Forward Propagation
       ↓
Calculate Loss
       ↓
Backpropagation
       ↓
Optimizer Updates Weights
       ↓
Validation
       ↓
Evaluation Metrics
       ↓
Analyze Model Performance
```
